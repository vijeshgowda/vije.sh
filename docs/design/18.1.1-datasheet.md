# V18.1.1 · Datasheet, usable

Prototype: `../18.1.1-datasheet.html` · 162 KB raw, 47 KB gzipped · Uses `../shared/content.js` · Brief: 18.1 with shadows fixed, more live feeds, small additions, and usability upgrades (the nav hid P7 Live behind a horizontal scroll on narrow screens). 18.1 stays untouched as the clean production candidate.

## 1. What changed from 18.1
Everything in [18.1-datasheet.md](18.1-datasheet.md) still applies except the items below. Storage keys use `v1811-`.

## 2. Shadows
| Problem in 18.1 | Fix |
|---|---|
| Two shadow languages: hard 3px offset on buttons, soft blur on cards | One elevation scale `--sh1/2/3`, each a tight contact shadow plus a soft ambient one from the same light (above); buttons use `--sh1`, lift to `--sh2` on hover, flatten on press |
| `.btn.red` used `clip-path` for its cut corner, which also clipped its own `drop-shadow`, so the main CTA had no shadow | Cut corner drawn by `linear-gradient(225deg, transparent 7px, red 7.5px) border-box`; `drop-shadow` now follows the shape |
| Dark mode shadows invisible (black on near-black) | Dark `--sh*` add a 1px inset top highlight; `--card` lifted to `#15161a` |
| Hovered card's big shadow painted under the next card | `.card:hover{z-index:2}`; rack units lift above neighbours |
| Globe shadow clipped at the bottom of the card and always brown | Radius `min(W,H)/2 − 34`, centre raised 6px, colour from `--sc` (30% light, 70% dark) |
| npm feed bars rendered as thin vertical lines (inline span) | `.nbar{display:block}` |
| `.card p` overrode `.fmsg` font size | `.card .fmsg{font-size:.74rem}` |

Light `--sc` is `70 48 24` (warm brown), e.g. `--sh2: 0 1px 2px rgb(sc/.08), 0 4px 10px -3px rgb(sc/.1), 0 16px 30px -12px rgb(sc/.24)`.

## 3. Header and navigation
- **Self-fitting header**: `fitNav()` measures the nav (`scrollWidth > clientWidth`) on load, resize and font load. Step 1 `.top.dense`: tighter link padding, search shows only its icon, theme label visually hidden. Step 2 `.top.compact`: links move into a dropdown behind a menu button. No fixed breakpoint, so it works at any width, zoom level or font. The nav never scrolls sideways (`overflow:hidden`).
- **Labelled menu button**: shows the current page (`P7 Live`), so people know where they are and that there is a menu; `aria-label="Menu, current page: Live"`.
- **Dropdown with descriptions**: each page gets one line (e.g. "Public data feeds: space, Earth, dev, AI") in a responsive two-column grid; current page has a red underline and tint.
- **Footer site map** on every page, plus a Search button.

## 4. Jump-to palette (Ctrl K / ⌘K, or the "Jump to" button)
`<dialog>` with a combobox input and listbox (`aria-activedescendant`). Items: 7 pages, 6 overview sections, every note, every thread, every feed (opens Live scrolled to the card) and commands (theme, flash firmware, kill a pod, launch, new thread, copy link, reset feeds, back to top). Multi-word filter (all words must match), arrows + Enter, hover selects, click outside closes. No single-letter shortcuts (WCAG 2.1.4).

`goTo(hash, selector, after)` navigates, then scrolls the target under the sticky header (`scroll-margin-top: 5rem`) and flashes a red ring. Because feeds above the target grow as they load, it re-aligns at 0.4, 1, 2 and 3.5 s unless the visitor scrolls, taps or types first.

## 5. Other usability upgrades
- **Back returns to where you were**: `history.scrollRestoration = 'manual'`; scroll position saved into `history.state` (debounced `replaceState`) and restored on hash change and reload.
- **Back to top** button after 1.5 screens, hidden while the footer is visible (it would cover Launch).
- **Toasts** (`role="status"`) for pins, refreshes, copied links, location errors.
- **Offline**: brand LED greys out, UART logs `net: link down`, toast explains feeds show cached data.
- **External links** carry `aria-describedby="newtab"` ("Opens in a new tab").
